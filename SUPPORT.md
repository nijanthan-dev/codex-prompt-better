# Support

Prompt Better is pre-alpha; there is no production support or working install.

- Usage/design question: GitHub Discussions when enabled; otherwise an issue.
- Reproducible bug or proposal: use an issue template.
- Vulnerability or sensitive report: follow [SECURITY.md](SECURITY.md).

Sanitize diagnostics. Never post prompts, sessions, databases, credentials,
tokens, personal data, or machine-specific paths.
